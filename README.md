# Tarayıcıda Çalışan Hafıza Oyunu

Bu proje, yalnızca HTML/CSS/JavaScript kullanılarak geliştirilmiş basit bir hafıza oyunudur.

## Çalıştırma

1. Proje klasörüne girin.
2. Aşağıdaki komutla basit bir sunucu başlatın:

   ```bash
   python3 -m http.server 8000
   ```

3. Tarayıcıda `http://localhost:8000` adresini açın.

## Oyun Kuralları

- Kartlara tıklayarak çiftleri bulmaya çalışın.
- Her iki kart seçimi bir hamle olarak sayılır.
- Tüm kartlar eşleştiğinde oyun biter.
