# Star Dodge

Star Dodge is a fast-paced browser game where the player pilots a ship to avoid incoming asteroids and survive for as long as possible.

[![CI](https://github.com/your-org/star-dodge/actions/workflows/ci.yml/badge.svg)](https://github.com/your-org/star-dodge/actions/workflows/ci.yml)

## Project Goals
- Keep gameplay simple and responsive.
- Maintain a clean, testable JavaScript codebase.
- Provide a polished interface suitable for portfolio presentation.

## Planned Milestones
1. Core gameplay loop and rendering.
2. Input handling and collision mechanics.
3. Score tracking and game-over flow.
4. Responsive styling and accessibility improvements.
5. Basic automated test coverage.

## Run Locally
```bash
npm install
npm run serve
```

Then open `http://localhost:4173` in your browser.
